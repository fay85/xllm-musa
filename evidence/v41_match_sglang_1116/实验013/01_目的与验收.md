# Draft 非因果 SWA 静态读取与 Graph

当前目标模型已跨层 Graph，但三层 draft 仍由主机逐算子发射。先实现动态 context GPU 标量与固定 shape 的非因果 SWA 读取，再对照静态但 Graph 关闭与三层 draft Graph，不能把两者混成一个可归因结论。

必须保留整个 proposal 块的双向可见性；所有 query 看全部 current KV。读取不提交 proposal KV，已接受 context 仍由 write_context_kv 单独写入。Graph 外继续处理 target auxiliary projection/context commit、词表头、Markov bias与采样。

先用 q1～6、历史0/越页/越SWA、负page padding、默认与非默认流比较原生产路径 rows/picks、MATE sparse 输出和 cache 不变；再用实际 Graph 更新 context、query、KV、table 和 sink 反复回放，防止冻结输入。通过后才运行完整模型两题、快筛、正式性能与独立trace。
