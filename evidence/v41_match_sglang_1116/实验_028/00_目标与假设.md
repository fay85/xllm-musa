# 实验028：让原生完整Graph中的GPU算子可见

这次只修复诊断能力，不更换模型计算或宣称性能晋级。E18仍是累计最佳；E23短上下文Indexer、E22小行mHC、E21复制Attention均保持关闭。

此前原生C++模型trace有GraphLaunch，但图内大部分GPU kernel不可见。E27最小图发现，当前torch_musa Python profiler只会刷新Python WeakSet登记的MUSAGraph；我方C++MusaGraphHandle不在其中。显式reinstantiate已捕获Graph后，两次独立采集均能看到Mul/Add，输入更新后的结果不变。因此本轮在原生图自身维护生命周期登记，在profiler启停边界刷新当前计算线程拥有的图。

目标：小图及八卡通信图输出不变；正式profiler关闭时性能稳定；真实1P1D独立采集中恢复图节点；关闭采集后服务继续正确运行。只验证当前一rank一进程、计算线程拥有图的用法，不声称覆盖其他worker线程或所有MUSA版本。
