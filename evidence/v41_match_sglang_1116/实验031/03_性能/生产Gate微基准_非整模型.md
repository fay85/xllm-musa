# 生产Gate独立微基准

80项路由检查、9次动态Graph通过，覆盖零行/1/4/6/7、BF16或FP32输入/权重、FP32缓存开关、默认/非默认流。实际复用V4原生MATE BMM后再调用V4.1 TopK；完整Gate的q4中位128.38→60.05us，反向129.92us。q1约91.35→60.96us，q6约121.19→60.42us。

这些是在单GPU下重复Graph回放的局部时间，不能直接乘层数预测真实模型吞吐。候选除了用BF16 GEMM输出FP32，还避免了旧路径逐次转换操作数；模型trace应核对真实变化。日志中“Mate 0.2.7 bmm active”是V4旧代码写死的文字，实际SO是隔离导出的donor MATE0.2.6产物e2654c9e…，以SHA为准。
