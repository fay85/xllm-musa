# E48 源码复核

范围：17d19adc 之后的三个 runtime 诊断文件；没有审查或改写无关模型代码。

- 默认没有 prefix/arm 时关闭；Graph warmup 和实际 capture 均不插入 event。
- thread_local 状态与当前诊断对象绑定，不跨线程复用；待上一条 event 完成才开始下一条采样，保持 request ID 与结果对应。
- 在实际 runtime stream 上记录边界；仅 query，不为取数额外 synchronize；报告明确跨流模型同步使其不是 kernel busy 时间。
- 采样间隔和条数有上限；局部 event 在结果取回后销毁。终止时可能尚有最后一条未就绪采样，不能拿采样条数推导完整执行轮数；正式 token 数和轮数来自请求及服务器日志。
- 数学运算、权重、token 提交和原先的同步调用未改。两道题与全部15个性能请求有效；8rank各47条event全部状态0，正式31条已按HTTP ID与暖机分开。
- 三份源码逐字节SHA与成功构建manifest相符。clang-format20.1.6 dry-run与git diff --check通过，完整MUSA构建exit0、ninja无待编译项；未声称其他后端已经编译验证。

结论：当前MUSA实验范围没有发现必须先修正的功能问题，可提交为默认关闭的诊断工具。该结论不等于模型精度验收，也不等于性能晋级。大trace/ELF仍留NFS，仓库保留可审查的源码、原始数据库/日志、摘要和图。
