# 候选组合边界

所有后续候选从适用范围内已经验收的最优配置出发。当前已接受的冷请求、非spec、C1基线为E38；packed shared完成两轮小幅正向，但保守不晋级。不能把尚未完成整机服务的DSpark称为新的最优。

- TP/EP custom AR、缓存读取复用、SWA读取融合、共享专家TP、D非默认计算stream、mHC归约融合：当前C1已接受。P端固定FFI准备同步与当前流collective完成边界，blocking wait关闭。
- packed shared/QKV仅q1生效，不能把它们在q>1 spec verify上的收益预设为非零。后续spec若成为新最优，涉及q1的专项要明确适用范围，不用一个实际未生效的开关声称累计提速。
- T10 bounded replay在late层裁减prompt行，当前实现显式拒绝全prompt辅助隐藏态capture。DSpark P端需要37/38/39层的完整辅助隐藏态；两者不能直接合开。CED作为非spec策略单独对比，并明确近似语义。
- T12 B2/B4目前只支持普通q1 decode请求的合批，spec当前显式C1限制不移除。C2/B1排队控制与B2/C2真合批在同并发、同cache预算、同非spec配置对照；不是与不同并发的MTP成绩简单相除。
- T11 prefix是另一种实际命中工作负载，不把warm-cache TTFT当cold改进。与DSpark同时启用还涉及完整aux/context KV复用，未验证前不合开。
- chunk512先在已验证的非spec基线上做严格单变量；与DSpark组合如有必要需另行核验context KV与辅助态容量。

当这些条件导致不能直接组合时，报告保留非spec C1、spec C1、不同并发及prefix/CED策略各自的结果，选择相应场景下的最优。不删除保护条件、不假定不同优化百分比可以相加。

所有性能结果仅通过基础功能检查，未完成模型精度验收；SOL口径未确定。
