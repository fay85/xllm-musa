# SGLang 本机 20k 参考：复验口径

此处“参考”指 SJ9→SJ10、8+8、GPU Engram 的本机变体。不是交付指南的 host Engram 或 C48。快报不能与 1+5 混均值。

|机制|已核实的证据|不应据此声称|
|---|---|---|
|硬件/版本|全新 P/D/Router；RepoDigest df978560…；源码 7c97bb0、MATE 0.2.6，Torch/Torch-MUSA 2.9.0；核对两侧 `environment.json` 与存活进程 maps/inode/SHA|历史失败进程也加载了相同库|
|P 并行|8 个调度 rank 的标记 ATTN_CP<i> TP<i> EP<i>。server_info: TP8/EP8、attn_cp_size=8、dp_size=1、interleave。源码 parallel_state.py 中 CP 宽=TP 宽时复用全 TP 组；MUSA 上 EP=TP 同样复用。此配置下 attention TP 是 8 个单元素组|CP8×TP8×EP8 需要 512 卡|
|D 并行|DP<i> TP<i> EP<i>。attention CP1，attention DP8 将请求分配到不同 DP rank；attention TP 宽为 1；全 8 rank 仍参与 EP。请求终态含 dp_rank；C1 不是 8 个并发用户|一条请求的 attention 分 8 卡扫同一序列|
|算子/图|P DeepEP normal，D low_latency，启动日志记录 LL masked preparation 和静态 scale；运行时加载的 mixed-dtype masked SO 552ca5a9…。P tail LOOKUP 后有源码 replay 路径，D graph=true，DSPARK5 每条有 verify/proposed/accepted|所有 shape 都使用同一 FP8 kernel|
|分配与容量|P expandable_segments=False。full 65536；P/D SWA 分别 9728/2304；有 D bounded replay，不能用 2304 对比整段 20000 就断定不能运行。P 真正按 8 块进入模型。D rank0 主/草稿权重约 67.29/1.47 GB，target/draft 图约 2.92/0.04 GB；详见各服务日志及 server_info|启动余量是压力峰值；允许直接将参数搬到 32k 或并发 48|
|mubin|已核实软件包 RECORD；0.2.6 实际以 504 个 .o 和 5 个 JSON 分发，不是 .mubin 后缀。日志提供 SO 名和哈希；未逐 kernel 追踪每个 .o 的调用|读取 RECORD 或映射 SO 就证明每个 mubin 执行过|
|缓存/终态|P/D disable_radix_cache=true；逐条要求 D 流的 request.finished 元数据、SSE id、length、实际 20000/1024、cached_tokens=0、reasoning_tokens=0、无 retraction|router HTTP 200 本身证明生成完整|
|输入/计时|D /v1/tokenize 的精确 IDs 对上冻结模板/词表；不把 reasoning_effort=none 当成 SGLang 原生支持，显式 chat 模板、实际 token 和无思考输出才是依据。EvalScope 首非空正文→最后成功解析 JSON 为现有计时边界|C1 是交付 C48 或五个样本足够估计 p99|

逐条验收用 `tools/musa_deepseek_v41/audit_sglang_long_c1.py`，入参为一组 performance/input… 目录、Decode server.log、实际 --length 与 --count。单独启动前记录脚本/库；服务预热的 4-token 非流式 /generate 不计入用户暖机。计分包含全部预定流；慢请求照计。P tail 的“整批 graph: False”不与内部尾部图矛盾；日志中 tag.strict 的 fallback 是包版本标签选择，不是量化 kernel 回退。

首组 S20A（1+5，6 条独立 ID 全对上 D 终态，退出后 16 卡释放）：正式均值 TTFT 7613.303 ms、TPOT 16.326 ms、E2E 24.315 s、42.114 token/s；单条 E2E 22.954–26.775 s；计分 verify 293–303 轮，accepted 723–733、proposed 1465–1515。暖机与计分独立。此时仅达 F1，不能宣布正式对照。
