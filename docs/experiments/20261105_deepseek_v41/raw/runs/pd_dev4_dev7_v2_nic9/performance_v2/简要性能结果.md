TPOT 采用官方 EvalScope 的 `(总时延−TTFT)/(输出 token−1)`，包含请求尾部开销；端到端输出 token/s 采用 `输出 token/总时延`，二者不能互换。

官方 EvalScope 会把 usage 计数写入数据库字段，但不把 choices=[] 的独立 usage 包保存到 response_messages。本报告按原生 request_id 与 P prefill、D 成功终止及 D sequence 计数逐条交叉核对，不仅依赖客户端 token 估算。原始 SQLite、工具保留的请求/响应 JSONL、匹配的服务端日志、逐次 CSV、标准差及最小最大值均保留。完整模型 P/D 路由、八卡拓扑与传输证据须另行核对；此客户端验收不替代服务端验收。
